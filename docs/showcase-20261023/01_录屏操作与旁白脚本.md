## 录制前准备

建议录成 5 分钟左右的主视频，另外保留一段动态 30 单完整运行素材。主线依次为：园区问题 → PPO 协同取件 → 动态订单 → 可解释决策 → 人工干预 → 实验依据。这里的完成是包裹回收到母车，不是送达最终收件人。

### 1. 启动与自检（不录入正片）

```text
cd D:\aitransformer\frontend
npm run demo
```

打开 http://127.0.0.1:3000/r3f.html。确认标题含“V2 · PPO 协同调度”，右上角为“后端已连接”。仅启动 Vite 不够；演示需要 Python 后端和 MQTT 通道同时在线。保持当前 V2 分支，不运行训练脚本或 legacy 模式。

先点击“重置”，等待仿真时间回到 0.0 s。选择“均衡 100%”，点击“演示视角”。建议浏览器最大化、1080p 以上、缩放 100%，关闭不相关通知。先录一小段检查文字清晰度、鼠标与旁白音量；场景加载完成后再开始。

打开“AI 调度”，如果显示“已配置 · 待联调”，先发送“全园区，所有无人机，常规取件，不设置能耗预算”。确认“后端已执行”和“AI 已连接”，再重置为干净开场。联网检查通过不等于已经执行过聊天，必须看执行回执。不要录制 .env、终端配置或任何 Key。

## 自然语言演示、结尾与长素材

### 3. 自然语言调度（约 03:05–04:10）

先点“重置”，字幕标注“新任务：自然语言干预”。展开右上角“AI 调度”，在“调度需求”输入以下原文，点击“发送调度指令”。

```text
派1号和3号无人机去B区取件，普通优先级，不设置能耗上限。
```

录下“AI 正在解析调度需求”到“后端已执行”的变化，并让结果中的“B 区、uav_1 / uav_3”与左侧分配同框。模型选定的订单编号可不同；若开局 B 区没有可取单，等动态到单后再看。UAV 2 保持待命是本次指令的预期效果。

旁白：大模型把自然语言转成设备和区域约束，PPO 再在约束内选单。它不是每一帧调用大模型驾驶无人机。真实接口不可用时，预设和开始任务仍能运行，但不能把预设演示说成大模型调用成功。

确认当前波次仍在运行，再输入下句。录到回执“当前波次完成后由 PPO 重新选单”和左侧“新调度待下波生效”；等待下一波，再录三机参与。

```text
切换为节能调度，全园区，所有无人机，单机能耗预算75%。
```

旁白：新的区域、设备和预算约束延迟到波次结束生效，避免中途丢失货物。75% 是当前单机调度能耗预算约束，不代表保证节省 75% 的能耗。最后输入“立即紧急停止所有设备”，确认回执与时间冻结；记录完可重置。

### 4. 结尾（约 04:10–05:00）

切入真实学习曲线和强基线结果图：512 个独立静态测试场景中，平均时延下降 1.72%，每单无人机能耗下降 2.29%，综合目标下降 1.92%。字幕同步注明“相对时间/能耗规则基线；静态离线环境”。

建议结尾旁白：本作品的价值是把协同策略、执行约束和可视化接成可验证闭环。目前动态订单已跑通，下一步针对动态到单重新训练并扩大评估，再逐步做实机标定。

### 5. 动态 30 单长素材

重置 → 均衡 100% → 演示速度 2× → 开始任务。保持全园区，不发 B 区或预算限制；持续录制到“30/30 单已回收至母车”、无人机全部归位。需要数分钟，充电会延长过程，不用固定倒计时催结束。剪成 10–20 秒快放时保留到达数与回收数，标注倍速。

## 发布口径与应急处理

### 6. 录制时容易误读的地方

| 现象 | 正确处理 |
| --- | --- |
| 显示“母车补能” | 这是电量约束下的正常等待。可作能力展示，或截取后续出发片段。 |
| 30/30 已卸货但仍在归位 | 继续等待全部归位、关舱和任务完成，不能提前说本轮结束。 |
| 区域指令后有其他区订单留着 | 它们仍存在，只是不在当前处理范围。完成当前范围不等于全园区任务完成。 |
| 没有看到正好 12 秒新增 | 12 秒是尝试补单间隔，点位占用会每 3 秒重试；暂停也会冻结计时。 |
| AI 鉴权失败或超时 | 检查后端配置、网络并重启本项目 MEC 服务；预设可用于继续演示，但须明确是预设。 |
| 后端离线 | 不要继续录成功流程。运行 npm run demo，待新鲜状态恢复后再重置录制。 |

### 7. 可直接使用的标题与简介

视频标题：NEXUS：让母车与无人机协同取件 | PPO 调度与三维仿真演示

视频简介：本作品实现一辆移动母车与三架无人机的园区协同取件仿真。集中式 PPO 选择订单和接应点，后端执行取件、排队回收和补能，三维控制台展示动态订单与实际指标，并支持自然语言施加调度约束。当前演示每轮最多 30 单；已完成真实 DeepSeek 调用与动态整轮回归。离线静态实验相对强规则基线有小幅改善，尚未接入实机。

## 无人机处理与运行验证

`scripts/prepare-matrice.py` 按获选资产的实际拓扑识别八片独立桨叶，断言数量，分为四个旋翼，保留材质和顶点属性，设 Y 轴轴心。固定电机外壳、相机、起落架与主体不会随旋翼一起转。仅删除独立 `polySurface4181` 展示箱组。处理后 GLB 为 42,266,676 B，删除展示箱减少 15,656 个可见三角形；没有用新几何体替代原始桨叶。

浏览器实际启停旋翼，并对比相同相机截图；机身、机臂与电机位置保持不变，只有桨叶角度变化。GLB 没有预制动画，当前旋翼动作由预览渲染驱动，不会生成后端任务状态或统计。处理输出记录在 `drones/matrice-300/flight-inspection.json`。

母车机械预览修复了 React 19 与 Drei Html Suspense 回退交互导致的加载异常，改用空回退；阴影类型明确为当前 Three 支持的 PCFShadowMap。舱盖改为向上开启，轮胎转角按实际显示位移累计。**舱盖下尚无真实接货开口和内部货仓，不能宣称装卸机构完成。**

## 截图和初步测量

实际 Chrome 视口 **2327 × 1105**，画布 DPR **1**，统一日光环境、ACES、曝光 1.0，中性地面，模型相机由包围盒与视口拟合。两栋楼均保存并人工查看斜角、正面、背面、屋顶截图：

- `output/browser/glass-{angle,front,back,roof}.png`
- `output/browser/london-{angle,front,back,roof}.png`
- `output/browser/drone-rotors-static.png`、`drone-rotors-moving.png`
- `output/browser/asset-evidence.json`：页面实际文本和视口记录。

页面连续测量约 2 秒一窗。玻璃楼一窗 20 帧：平均 100.05ms、P95 110.2ms，约 10FPS，175 draw calls，1,932,267 triangles（含透明材质及阴影多次绘制），8 个当前页纹理资源。伦敦楼一窗 25 帧：平均 80.05ms、P95 110.1ms，约 12FPS，89 calls，172,004 triangles（含阴影）；页内切换后纹理累计 51 个，不是伦敦楼独占纹理数。无人机截图时约 20FPS / 146 calls / P95 90ms。

这些是当前机器多页面浏览器运行环境的短窗初测，窗口之间有波动，**不是独占 GPU 基准或 G5 稳定性能验收**。没有为了提高数字删掉主模型细节，也不保证 60FPS。浏览器缓存下重新加载实测模型解码及加载约玻璃楼 0.70s、伦敦楼 0.71s、无人机 0.36s；不含 HDRI、首次网络下载、GPU 编译或完整首帧。

# 科技感日光动画风园区展示 · 2026-10-15

在现有 Three.js / React Three Fiber 数字孪生项目中完成一轮展示层重建。视觉采用蓝白玻璃建筑、暖浅砂灰铺装、清爽草绿、青色科技点缀和圆润绿化；保持晴天明亮的场景，不做昼夜切换。主要入口为 `/r3f.html`，独立静态预览为 `/campus-preview.html`。

## 场景与材质

- 主楼继续使用已通过许可核验的办公楼 GLB。补齐玻璃几何的投影 UV，使原文件没有 UV 的幕墙能够显示低频蓝灰反射；太阳能板使用程序绘制的深蓝电池格。材质只做前端克隆，GLB 源文件和模型几何不被覆盖。
- 通过 `prepare-tech-context.mjs` 从同一办公楼派生独立周边建筑 GLTF，去除椅子和小尺度窗框，将单体简化到约 5,019 面；在园区外侧道路排布 32 栋楼。所有楼体来自真实获选 GLB，不以方块拼主楼。
- 中央作业广场使用低对比度灰蓝铺装，环绕较深的石板蓝道路、人行道、停车标线和入口支路；绿地采用低饱和自然绿。中央 64×64m 作业区保持可通行，景观床、灌木、树木和灯具落在路线以外。
- 2026-10-15 晴日调色：任务地图改用 Poly Haven Qwantani Noon clear-sky HDRI（CC0），提高暖色定向日光、降低半球/环境填充光，雾色转为清亮浅蓝并后移，墙面和铺装加入柔和暖色。独立预览与任务地图共用同一光照设置。
- `CampusForecourt` 提供起降标记、路缘角标、停车格和调度终端；它们是浅层地面标识或低矮环境物件，不占无人车行驶空间。
- 主园区道路增加外环、内环、四条接驳口、楼前车辆支路和步行捷径；内环接入口配有减速横道，环路补充短虚线车道标记。内环按 5.2m、外环按 6.4m 设计，步行主路宽 3.2m，楼间小径宽 2.6m，车辆与步行路线能读成不同层级。
- 六栋主办公楼在 3F、5F、7F、9F 加装轻量化阳台：圆角楼板、玻璃栏板、金属扶手、立柱、支撑和成簇低多边形花箱；共 6 个订单放在 3F 至 7F 阳台，另外 2 个仍在中庭。包裹中心在阳台板面上方 0.25m，包裹清单和地图标注楼栋与楼层。
- `src/core/campusPickupLocations.json` 是业务与显示共用的点位源。前端以同一坐标放置包裹和阳台，后端将六个高层目标送入既有任务轨迹与精确悬停判定；无人机保持在包裹上方约 0.95m 完成悬停和装载，楼上订单不是抬高的装饰模型。
- `/campus-preview.html` 复用同一 3D 园区与设备模型，独立预览界面也换成深蓝玻璃卡片与青色交互色，避免主展示和预览各用一套 UI 观感。

## 设备动作与控制

- 无人机保留已授权 Matrice 300 GLB。飞行时机身按速度和转弯做轻微俯仰/侧倾，四组桨叶绕各自枢轴旋转；静止时电机平滑降速。没有让机身整体旋转。近、中、远 LOD 共用动画枢轴和世界变换。
- 母车使用已确认的原创无驾驶室物流母车模型；车轮、转向与接货舱门继续按后端遥测驱动。轨迹、包裹夹取、入舱和任务阶段沿用现有渲染逻辑。
- 自由镜头保留 WASD 平面移动、Q/E 或空格/Ctrl 升降、Shift 加速、右键锁定转向、Esc 退出；业务任务开始、暂停、重置和统计仍由后端状态驱动。

## 业务边界

保留 MQTT 前后端连接、ONNX 后端推理、任务分配、到达条件、取件/回收时序、任务控制和数据统计。新增的 6 个楼层目标只调整订单坐标，派送算法、精确到达条件和装载规则仍在后端执行；神经网络推理没有迁回浏览器。AI 自然语言网关仍按之前约定保留为“已配置、待用户联调”。

## 性能记录限制

当前机器 WebGL renderer 是 Intel UHD Graphics 770，不是 RTX 3060。一次默认场景截图记录 313 draw calls、564,127 renderer triangles、259 geometries 和 21 textures；renderer 读数包含当前视图和渲染通道，不能与上面的独立资源预算直接互换。采样窗口出现约 1 秒帧间隔且只有两帧，属于被节流的无效帧率样本，因此不据此推算 3060 FPS。目标 3060 上的稳定帧时间仍需在目标显卡与正常前台条件下测量。

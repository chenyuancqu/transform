# RTX 3060 预算优化与圆润日光版本 · 2026-10-14

本轮按用户最新要求，将视觉方向改为更明快、圆润的动画风格；默认任务入口和独立预览均实际更新。原办公楼模型继续作为主建筑，任务计算、坐标、到达阈值、取件/卸货时序及统计由原后端执行。

改造前建立分支 `optimize-rtx3060-20261014`，展示与配置文件备份在 `output/checkpoints/rtx3060-20261014`。保留原素材及其他未提交改动。

## 实际改动

- 替换稀疏的写实树木：官方 Kenney Nature Kit（CC0）导入 OBJ，树冠两次 Loop 细分、恢复丰满体积、重算法线并重新配色，输出真实 GLB。32 棵团簇树、16 棵阔冠树、64 株灌木以 5 次实例化绘制完成；另有 1 次座椅实例化。
- 团簇树 4,600 面、阔冠树 650 面、灌木 640 面。实体不透明树冠不使用高分辨率叶片贴图及层叠 alpha 卡片。来源、改造和许可见 [资产许可](asset-licenses.md)。
- 草地采用浅绿、铺装采用暖米色，道路采用蓝灰色哑光材质；取消默认场景的地面扫描贴图加载。天空、填充光、玻璃颜色及 tone mapping 调整为通透日光。
- 删除办公楼内昂贵的椅子网格，保留外立面、楼层、屋顶、入口与建筑尺寸。标准楼原模型 650,371 面降至 19,330；低层中心 267,859 面降至 6,154，均未计原创入口/屋顶细节。外部包围盒验证不变。
- 六栋相同办公楼及其静态建筑细节采用实例化，完整建筑群约 24 个渲染网格；118 处道路标线合为 1 次绘制，8 盏路灯合为 3 次绘制。
- 无人机近/中/远 LOD 分别 140,387 / 43,389 / 19,584 面；母车近/中 LOD 分别 87,996 / 31,407 面。数字已计入重复使用网格的场景实例。母车近景保留全部原面数。设备材质/贴图跨 LOD 复用；无人机远景合并相近的深色塑料材质。
- 所有 LOD 保留真实旋翼、车轮、转向与舱门枢轴及其世界变换。更新所有 LOD 的旋翼/舱门状态，切换细节时不会重新开始动画。
- 建筑玻璃和无人机镜片取消物理折射，使用轻量透明混合；避免为小镜片或整栋楼额外渲染整幅场景。玻璃外观更浅、更清爽。
- DPR 固定为 1，阴影从 4096 降为 2048；暂停时复用阴影，运行时最多 30Hz 更新。LOD 切换及暂停位置修正会更新阴影。
- 静态园区不随遥测反复渲染 React 组件，标签缓存对象引用，轨迹在距离足够变化时更新，诊断 DOM 降频更新。
- 入舱近景发现低帧率暂停可能冻结在滞后的插值位置；现暂停显示对齐最后的后端遥测坐标，恢复时继续平滑移动。后端判定规则未改变。实测卸货暂停时母车位置 `[-26.8688,0,30]`，舱口偏移后为 `[-26.7188,*,30]`，无人机位置与该舱口对齐。

## 几何与资源预算

优化前资产核算约 **79,575,703 个三角面**（独立场景实例口径，包含高精度绿化）。当前核算文件：`output/rtx3060-20261014/asset-budget.json`。

| 项目 | 当前三角面 |
|---|---:|
| 7 栋建筑及原创建筑细节 | 152,108 |
| 全部树木、灌木、座椅 | 203,600 |
| 全部设备使用近景 LOD | 509,157 |
| 全部设备使用远景 LOD | 90,159 |
| 地面、目标包裹、吊具等辅助预算 | 25,000 |
| 全场景近景上界预算 | **889,865** |
| 全场景普通远景预算 | **470,867** |

近景上界是预算：实际相机不可能同时靠近所有分散物体，绘制还受视锥裁剪影响。辅助几何采用预留预算，未冒充逐个物体的精确实测。多次阴影/透明绘制应另计，不能与独立三角面混淆。

当前默认入口使用的全部模型、所有设备 LOD、共享贴图和 HDRI 文件合计 **20,215,113 字节，约 19.28 MiB，共 22 个文件**；不包括 JS/CSS、MQTT 流量和运行时生成贴图。此前同口径资源约 485.55 MiB。原下载素材仍在 `public`，Vite 会复制到 `dist`；**整个发布目录不是 19MB**。这些备份不会被默认入口请求，分发包裁剪是后续单独工作。

## 浏览器检查与性能实测边界

主视角移除物理折射后观测 **255 次绘制、458,641 个渲染三角面**，GPU 纹理计数 21。此采样为暂停取件状态；对应 JSON 在 `output/rtx3060-20261014/main-view-metrics.json`。实际渲染负载会随相机、阴影更新和任务状态改变。

本机实际 WebGL renderer 为 **Intel UHD Graphics 770 / ANGLE D3D11**，并非 RTX 3060。请求 1920×1080 测试尺寸后，浏览器实际 Canvas 为 **1745×981**；记录实际尺寸，未把它伪称为准确 1080P。临时尺寸已恢复。

本轮多段帧间隔采样呈现约 1,000ms 的固定间隔。窗口节流、其他页面和当前系统负载未能独占排除；没有 GPU 时间查询/CPU 火焰图证明原因。保留原始平均/P95 记录，**不将其作为有效硬件性能验收，不推算 RTX 3060 FPS**。资产预算与绘制量已达到本轮目标；RTX 3060 在 1080P、DPR 1 的稳定帧率仍需在目标机器验收，G5 的目标机 FPS 项尚未完成。
